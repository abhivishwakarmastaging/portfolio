# Abhishek Vishwakarma Portfolio

Next.js portfolio for a React Native + Full Stack developer.

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Personalization

Replace the placeholder contact links in `app/page.tsx` with your real email, LinkedIn, GitHub and phone number. Replace `public/profile.jpg` with a professional headshot if desired.

The resume PDF is expected at `public/Abhishek_Vishwakarma_Resume.pdf` when you copy the delivered resume into the project.
